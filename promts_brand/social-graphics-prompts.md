## General Social Graphics Guidelines

### Color Usage:
- **Primary Background:** White (#FFFFFF) or Light Cloud (#F8FAFB)
- **Accent Background:** Gradient Cyan (#00B4D8) to Teal (#06D6A0)
- **Professional Background:** Deep Ocean Blue (#0A2E4D)
- **Text Overlay:** Always ensure sufficient contrast (WCAG AA minimum)

### Typography Spacing:
- **Headlines:** Leave 200-300px height clear
- **Body Text:** Leave 400-500px height clear
- **Margins:** Minimum 80px from edges for safety
- **Mobile Preview:** Test at 25% size for readability

### Logo Placement:
- **Primary Position:** Bottom-right corner
- **Size:** 60-80px square
- **Margin:** 60px from edges
- **Opacity:** 100% on white, 80% on gradients

### Export Specifications:
- **Format:** PNG with transparency, JPEG for solid backgrounds
- **Quality:** 90-95% for JPEG, maximum for PNG
- **Color Profile:** sRGB for social media
- **Dimensions:** Exact pixel dimensions per platform

### Platform-Specific Optimization:

**Instagram:**
- Bright, vibrant colors perform better
- High contrast for small mobile screens
- Test in feed view (reduced size)

**Twitter/X:**
- Headers: Keep important elements in outer thirds
- Posts: Square format performs well
- Avoid center placement (profile photo overlap)

**LinkedIn:**
- Professional, subdued aesthetic
- Corporate color palette emphasis
- Clean, sophisticated designs

### Accessibility Requirements:
- **Text Contrast:** Minimum 4.5:1 ratio
- **Large Text:** Minimum 3:1 ratio (18pt+)
- **Color Alone:** Never rely solely on color to convey info
- **Alt Text Ready:** Design with description in mind

- [ ] File size optimized (under 1MB for fast loading)
- [ ] Exported in correct dimensions for platform
