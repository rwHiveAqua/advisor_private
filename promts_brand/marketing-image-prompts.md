## General Marketing Image Guidelines

### Color Grading for Photography:
**Lightroom/Photoshop Settings:**
```
Exposure: 0 to +0.3 (keep bright)
Contrast: +5 to +10 (subtle)
Highlights: -10 to -20 (prevent blowout)
Shadows: +15 to +25 (lifted, not crushed)
Whites: -5 (preserve detail)
Blacks: +10 (milky shadows)
Clarity: +3 to +8 (subtle sharpness)
Vibrance: +10 to +15 (natural saturation)
Saturation: -5 to -10 (muted, professional)
Temperature: +2 to +5 (slightly warm)
Tint: +2 to +3 (reduce yellow cast)
```

**Selective Color Adjustments:**
- Blues: Shift toward cyan, increase saturation +15%
- Cyans: Boost luminance +10%
- Greens: Shift toward teal if present
- Skin tones: Keep natural, slight warmth

---

### Composition Best Practices:

**Hero Images:**
- Leave 40-50% negative space for text (usually top-right or left third)
- Place focal point using rule of thirds
- Ensure clear visual hierarchy
- Test with actual headline overlay

**Feature Illustrations:**
- Central focal element, balanced composition
- Generous white space (30-40% of canvas)
- Single concept per illustration
- Clear, instantly understandable

**Background Images:**
- Very subtle, low contrast
- Should never compete with foreground text
- Opacity typically 5-15% for overlays
- Test with dark AND light text

---

### Technical Specifications:

**Export Settings:**
- **Format:** WebP (primary), JPEG (fallback), PNG (if transparency needed)
- **Quality:** 85-90% for JPEG, maximum for WebP
- **Color Space:** sRGB for web
- **Resolution:** 2x actual display size for retina (then resize)

**File Size Targets:**
- Hero images: < 300KB
- Feature illustrations: < 150KB
- Email headers: < 100KB
- Social images: < 200KB

**Responsive Versions:**
- Desktop: Full size (1920px width)
- Tablet: 1200px width
- Mobile: 800px width
- Use `<picture>` element with srcset

---

### Overlay Text Contrast:

**For Text Overlays, Add:**
```css
/* Dark gradient overlay */
background: linear-gradient(
  180deg,
  rgba(10, 46, 77, 0) 0%,
  rgba(10, 46, 77, 0.7) 100%
);

/* White text on dark overlay */
color: #FFFFFF;
text-shadow: 0 2px 4px rgba(0, 0, 0, 0.2);
```

**Or light overlay:**
```css
/* Light overlay for dark text */
background: rgba(255, 255, 255, 0.85);
backdrop-filter: blur(10px);
color: #0A2E4D;
```

---

### Accessibility Requirements:

**Contrast Ratios:**
- Text on images: Minimum 4.5:1 for body, 3:1 for large text
- Always test with WebAIM contrast checker
- Provide text alternatives for all images

**Alt Text Templates:**
```
Hero: "Knowledge worker in focused work session at clean home office desk"
Feature: "Illustration of AI-powered insight generation from work patterns"
Background: "Subtle gradient background in brand colors" or decorative ""
```
