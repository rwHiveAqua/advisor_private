## General Logo Refinement Guidelines

### For All Concepts:

**Color Accuracy:**
- Primary: Deep Ocean Blue #0A2E4D
- Gradient Start: Insight Cyan #00B4D8
- Gradient End: Transformation Teal #06D6A0
- Background: Pure White #FFFFFF

**Size Specifications:**
- Generate at minimum 1024x1024px
- Upscale to 2048x2048px for print
- Maintain 1:1 aspect ratio
- Create versions at 512px, 1024px, 2048px

**Style Requirements:**
- Vector art aesthetic (even from AI)
- Clean edges, no blur
- Minimal design, geometric precision
- Professional technology brand feel
- No shadows, textures, or 3D effects
- Generous white space

**Post-Processing Steps:**
1. Generate initial concept
2. Remove background if needed (use remove.bg or Photoshop)
3. Adjust colors to exact hex values in vector editor
4. Clean up any rough edges
5. Export as SVG, PNG (with transparency), and WebP
6. Create monochrome versions (all Deep Ocean Blue #0A2E4D)
7. Create white version for dark backgrounds

**Variations to Create:**
- Full color gradient version
- Monochrome dark (Deep Ocean Blue)
- Monochrome light (White)
- Monochrome black (for print/legal)

## Platform-Specific Optimization

### Midjourney Best Practices:
- Use `--style raw` for less artistic interpretation
- Keep `--stylize` between 50-100 for logos
- Use `--quality 2` for final versions
- Try `/describe` on reference logos for style matching
- Use remix mode to iterate on specific aspects

### DALL-E 3 Best Practices:
- Be extremely specific about colors (include hex codes)
- Emphasize "vector art style" repeatedly
- Request "clean edges" and "professional design"
- Mention "no shadows" and "white background" explicitly
- Use ChatGPT Plus for higher quality outputs

### Stable Diffusion Best Practices:
- Use detailed positive prompts
- Comprehensive negative prompts are crucial
- Generate multiple variations (batch of 4-8)
- Use img2img to refine best candidates
- Apply vector art LoRA if available
- Upscale final selection with R-ESRGAN
