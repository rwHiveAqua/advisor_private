## Illustration Style Guidelines

**Visual Aesthetic:**
- Modern, minimal, geometric with organic touches
- Line-based (2px weight) with selective fills
- 2-3 colors maximum per illustration
- Slightly rounded corners (4px border-radius on shapes)
- Friendly but not childish, professional but not corporate

**Typical Dimensions:**
- Standard: 400x400px (square format)
- Wide: 600x400px (landscape for headers)
- Vertical: 400x600px (portrait for mobile)
- Large: 800x800px (high-res versions)

## General Production Guidelines

### Size Specifications by Use Case

**Mobile App (Portrait):**
- Standard: 400x600px
- Large: 600x900px
- DPI: 72 (screen optimized)
- Format: PNG or SVG

**Web App (Square):**
- Standard: 400x400px
- Large: 800x800px
- DPI: 72
- Format: SVG preferred, PNG @2x fallback

**Web App (Landscape):**
- Standard: 600x400px
- Large: 1200x800px
- DPI: 72
- Format: SVG preferred

**Export multipliers:**
- @1x: Base size
- @2x: 2× base (retina)
- @3x: 3× base (super retina)

---

### Color Usage Rules

**Maximum Colors Per Illustration:** 3-4 including background

**Approved Color Combinations:**

**Primary (Professional):**
- Deep Blue #0A2E4D + Cyan #00B4D8 + White background
- Deep Blue + Teal #06D6A0 + White background

**Secondary (Encouraging):**
- Cyan #00B4D8 + Teal #06D6A0 + White/Lavender background
- Medium Gray #6B7888 + Cyan + White background

**Accent (Special moments):**
- Primary combo + Dawn Gold #FFD166 (sparingly, <10% visual weight)
- Primary combo + Warm Coral #FF6B6B (for alerts, gently)

**Empty States (Soft):**
- Soft Gray #E4E9F0 + Medium Gray #6B7888 + White background
- Light Cloud #F8FAFB background with Soft Gray elements

---

### Line and Shape Specifications

**Line Weights:**
- Primary elements: 2px stroke
- Emphasis elements: 3px stroke
- Subtle/background: 1px stroke
- Never below 1px or above 3px

**Corner Radius:**
- Small elements: 4px border-radius
- Medium elements: 8px border-radius
- Large elements: 12px border-radius
- Circles: Always perfect circles (not ovals)

**Stroke Style:**
- Line caps: Rounded
- Line joins: Rounded
- Dashed lines: 2px dash, 3px gap pattern

---

### Composition Guidelines

**Whitespace:**
- Minimum 15% padding on all sides
- Center important elements vertically and horizontally
- Use rule-of-thirds for asymmetric compositions

**Visual Hierarchy:**
- Primary element: Largest, most saturated color
- Secondary element: Medium size, supporting color
- Tertiary element: Small, accent or subtle color

**Balance:**
- Symmetric for stability (onboarding, success states)
- Asymmetric for movement (empty states, CTAs)
- Diagonal for progress/growth narratives

---

### Google Imagen Specific Tips

**For Best Results:**
1. Always specify exact pixel dimensions
2. Include "2px stroke weight" explicitly
3. Specify "rounded line caps and joins"
4. Request "clean vector style illustration"
5. Include "generous whitespace" or "centered composition"
6. Specify background color explicitly (usually white)

**Negative Prompts (Always Include):**
```
"realistic, photographic, 3D, shadows, drop shadows, gradients on background, texture, noise, complex details, many colors, busy, cluttered, low quality, blurry, distorted"
```

**Additional Negative for Characters:**
```
"detailed faces, realistic people, photographs, complex clothing, hair details"
```

**Imagen Parameters:**
- Guidance scale: 14-18 (higher = more literal interpretation)
- Aspect ratios: Use standard ratios (1:1, 3:2, 2:3, 3:4, 4:3)
- Seed: Set for consistency across related illustrations

### Animation Considerations

**For Animated Versions:**

**Onboarding Welcome:**
- Animate: Door opening (0.5s), path drawing (1s), figure walking (1.5s)
- Easing: ease-in-out
- Loop: No (plays once)

**Tutorial Focus:**
- Animate: Focus beams pulsing inward (2s loop), sparkle fade-in
- Easing: ease-in-out for beams, ease-out for sparkle
- Loop: Yes (continuous subtle pulse)

**Success Checkmark:**
- Animate: Progress ring drawing (0.8s), checkmark stroke (0.4s delay), sparkles appear
- Easing: ease-out for ring, spring for checkmark
- Loop: No (plays once)

**Empty States:**
- Animate: Subtle floating/breathing motion (3s loop)
- Easing: ease-in-out
- Loop: Yes (very subtle, calming)

**SVG Animation Export:**
- Use CSS animations or SMIL
- Keep file size under 150KB with animation
- Provide static fallback version
- Test performance on mobile devices

---

### Accessibility Notes

**For Screen Readers:**
- Provide descriptive alt text for all illustrations
- Example onboarding: "Illustration of person entering doorway to growth journey"
- Example empty state: "Empty timer icon indicating no sessions yet"
- Example success: "Checkmark icon in circular progress ring indicating completion"

**For Visual Accessibility:**
- Use minimum 3:1 contrast ratio for elements
- Don't rely solely on color to convey meaning
- Include shape/icon differences for states
- Test in grayscale to ensure clarity

**For Motion Sensitivity:**
- Provide static versions of animated illustrations
- Respect `prefers-reduced-motion` CSS media query
- Keep animations subtle and slow (2-3s minimum)
- Avoid rapid flashing or jarring movements

## Context-Specific Variations

### Dark Mode Versions

**Color Inversions:**
- Background: White #FFFFFF → Dark #1F2937
- Deep Blue #0A2E4D → Cyan #00B4D8
- Soft Gray #E4E9F0 → Medium Gray #6B7888
- Maintain: Cyan #00B4D8, Teal #06D6A0, accent colors

**Adjustments Needed:**
- Increase line weights slightly (2px → 2.5px) for visibility
- Add subtle glow (1px outer glow, 20% opacity) on primary elements
- Reduce opacity of background gradients (50% instead of 100%)

**Google Imagen Prompt Addition:**
```
"Dark mode version: dark gray #1F2937 background instead of white, adjust element colors for dark UI, maintain cyan and teal brand colors, increase contrast for visibility"
```

---

### Reduced Motion Versions

**For Users with Motion Sensitivity:**

Static alternatives for all animated illustrations:
- Show final state of animation
- Use directional arrows or indicators instead of motion
- Include "play" icon overlay on static version
- Provide same information without animation

Example: Instead of beams pulsing on focus tutorial, show static beams with small "focus" label.
